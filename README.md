## 🧠 Habilidades Técnicas Desenvolvidas

Durante o bootcamp de Análise de Dados da DIO, adquiri e pratiquei diversas competências essenciais para atuar na área de dados. Aqui estão as principais:

### 📊 Fundamentos de Análise de Dados
- Entendimento de tipos de dados e estatísticas básicas
- Processos de ETL (Extração, Transformação e Carga)
- Análise exploratória e geração de insights

### 🐍 Programação com Python
- Manipulação de dados com **Pandas** e **NumPy**
- Visualizações com **Matplotlib** e **Seaborn**
- Web scraping com **BeautifulSoup**
- Criação de scripts automatizados para análise

### 🗃️ Banco de Dados e SQL
- Criação e consulta de bancos relacionais
- Comandos SQL: SELECT, JOIN, GROUP BY, HAVING, etc.
- Extração de informações relevantes para tomada de decisão

### 📈 Business Intelligence com Power BI
- Criação de dashboards interativos
- Modelagem de dados e uso de DAX
- Apresentação de KPIs e relatórios visuais

### 📁 Excel Avançado
- Tabelas dinâmicas e gráficos
- Fórmulas e funções para análise de dados
- Organização e limpeza de bases

### 🤖 Introdução à Inteligência Artificial
- Aplicações básicas de IA em análise de dados
- Uso do Azure Machine Learning em projetos práticos

### 🧰 Ferramentas Complementares
- Versionamento de código com **Git e GitHub**
- Ambiente de desenvolvimento com **VS Code**
- Automação e produtividade com **Microsoft Copilot**
  
Essas habilidades me capacitam para atuar em projetos de análise de dados, BI, automação de relatórios e apoio à tomada de decisão baseada em dados.
